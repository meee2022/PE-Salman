دليل تصميم التوجيه التربوي للتربية البدنية

توثيق كامل للهوية البصرية: الألوان، الخطوط، البطاقات، الأزرار، الجداول، التدرّجات، والحركات — مع أمثلة حيّة وكود جاهز للنسخ لاستخدامه في أي مشروع آخر بنفس الهوية.

الخطوط (Typography)

الخط الأساسي Cairo (مع Tajawal بديلًا). تدرّج الأوزان من 300 إلى 900 يصنع الهرمية البصرية كلها.

عنوان رئيسي — وزن 900
عنوان قسم — وزن 800
عنوان فرعي — وزن 700
نص عادي للقراءة — وزن 500، وهو الأكثر استخدامًا في الفقرات والبيانات.
نص ثانوي وملاحظات — وزن 400 بلون هادئ.
الاستيراد + التطبيق
@import url('https://fonts.googleapis.com/css2?family=Cairo:wght@300;400;500;600;700;800;900&family=Tajawal:wght@400;500;700;800&display=swap');

* { font-family: 'Cairo', sans-serif; }
html { direction: rtl; }

البطاقات (Cards)

ثلاثة مستويات: card القياسية، card-luxurious الفاخرة (زوايا أكبر + ظل مركّب)، وmodule-card لبطاقات التنقّل. السر في الظلال المركّبة الناعمة وزوايا 16–24px.

بطاقة قياسية
‎.card + .card-hover — زوايا 16px وظل خفيف يرتفع عند المرور.
بطاقة فاخرة
‎.card-luxurious — زوايا 24px وظل ثلاثي + توهج ذهبي عند المرور.
★
بطاقة قسم
‎.module-card للتنقّل

.card {

  box-shadow: 0 1px 2px rgba(42,20,24,0.04), 0 8px 24px -12px rgba(42,20,24,0.10);
  transition: box-shadow .25s ease, transform .25s ease;
}
.card-hover:hover {
  transform: translateY(-2px);
  box-shadow: 0 2px 4px rgba(42,20,24,0.06), 0 18px 40px -16px rgba(92,21,35,0.22);

بنية الصفحة — من الأعلى للأسفل
① الشريط العلوي (TopBar): شفّاف مع backdrop-blur، شعار (icon-orb عنابي) + تنقّل أفقي (العنصر النشط بخلفية عنابية ونص أبيض) + بحث + جرس تنبيهات + قائمة الملف. ارتفاع ثابت 60px، sticky أعلى الصفحة.
② الهيرو الترحيبي: .hero-gradient-premium + نقش أرابيسك، عنوان ترحيبي + السنة الدراسية.
③ شريط المؤشرات (KPI): شبكة 4 بطاقات .card (رقم كبير وزن 900 عنابي + عنوان صغير هادئ).
④ المحتوى الرئيسي: شبكة بطاقات .card-luxurious — رسوم بيانية، جداول، لوحة صدارة بأوسمة crown.
⑤ التنقّل السفلي (موبايل): شريط سفلي ثابت بـ backdrop-blur + 4–5 تبويبات (.tab-item) وزر "المزيد".
⑥ المساعد الذكي: زر عائم أسفل اليسار يفتح نافذة محادثة.
القياسات والمسافات المعتمدة
الحاوية القصوى:   max-width: 1100–1280px; margin: 0 auto;
الحشو الأفقي:     16–24px (موبايل/سطح مكتب)
المسافة بين الأقسام: 20px (space-y-5)
زوايا البطاقات:   16px (card) · 24px (luxurious) · 12px (أزرار/حقول)
ارتفاع TopBar:    60px   |   ارتفاع BottomNav: 64px
منحنى الحركة:     cubic-bezier(0.16, 1, 0.3, 1)  — "ease-out-expo" ناعم
📦 للاستخدام في مشروعك الجديد: انسخ كتلة :root + كلاسات المكوّنات من هذا الملف مباشرة (كلها CSS صرف بدون اعتماديات). لو بتستخدم Tailwind، انسخ كتلة colors أعلاه. الخط Cairo من Google Fonts. اضبط html { direction: rtl; } للعربية.
